# Training Plan

Audience

- Analysts
- Business users
- Power BI consumers

Format

- 60-minute live workshops
- 1-hour recorded video walkthroughs
- Quick reference cheat-sheets

Topics

- How to use the dashboard
- How to export data and create ad-hoc reports
- Understanding model outputs and limitations

Metrics

- Attendance rate
- Post-training survey (satisfaction & usefulness)
