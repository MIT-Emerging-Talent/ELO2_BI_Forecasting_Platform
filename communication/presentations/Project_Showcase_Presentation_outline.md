# Project Showcase Presentation - Slide Outline

Follow this outline to build `Project_Showcase_Presentation.pptx` (18-20 slides).

1. Title Slide
   - Project title, subtitle, presenter, date

2. Executive Snapshot
   - One-paragraph summary and 3 key metrics

3. Problem & Opportunity
   - Business context and opportunity statement

4. Data Sources & Scope
   - Datasets used (Olist, Superstore, World Bank)
   - Time period and geographic focus

5. Architecture Overview
   - 3-layer design: transactional, operational, macro
   - Star schema diagram (add image)

6. ETL Pipeline
   - Data flow diagram and quality checks

7. Exploratory Analysis Highlights
   - Price and order distributions (add charts)

8. Category Performance
   - Top 5 categories and resilience metrics

9. Economic Context
   - Inflation & GDP trends and their effects

10. Forecasting Approach
    - Model types, features, train/test split

11. Forecast Results
    - R², MAE, RMSE summary (table)

12. Scenario Analysis
    - Recession and recovery scenarios (charts)

13. Key Recommendations
    - 3-5 concrete, actionable recommendations

14. Business Impact
    - Estimated savings, accuracy improvements, ROI

15. Implementation Roadmap
    - Next steps and timeline

16. Demo / Live Dashboard (optional)
    - Screenshot(s) from Power BI

17. Lessons Learned
    - Challenges and what worked well

18. Q&A / Appendix
    - Contact info, links to repo and docs

---

Notes:
- Use screenshots and charts from `2-analysis-and-results/results/` and the Power BI export.
- Keep each slide visual-first; use talking points in slide notes.
- Timing: target 18 minutes + 6 minutes Q&A (1 minute per slide).
