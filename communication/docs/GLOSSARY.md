# Glossary

Key terms used across the project.

- ETL: Extract, Transform, Load — data processing pipeline steps.
- KPI: Key Performance Indicator — high-level metrics such as revenue, margin.
- R²: Coefficient of determination — model fit metric.
- MAE: Mean Absolute Error — prediction error metric.
- PBIX: Power BI Desktop file format.
- GDP: Gross Domestic Product — macroeconomic measure; used here as an explanatory variable.
- Inflation: General price-level change — used to compute real (inflation-adjusted) revenue.
- Master dataset: The consolidated, cleaned dataset used for modeling and reporting.

If you want a term added, open a PR with the definition.
